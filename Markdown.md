
# Guia d’Inici a Markdown

## Què és Markdown?

**Markdown** és un llenguatge de marcat senzill que permet escriure text pla amb una sintaxi especial per a donar-li format: títols, negreta, cursiva, llistes, taules, enllaços, imatges i molt més.

El seu objectiu principal és fer que l’escriptura siga més clara i neta, sense haver d’utilitzar menús com en Word o Google Docs. És molt usat en GitHub, blocs, documentació tècnica i educació.

---

## Per què utilitzar Markdown?

- És **ràpid** d’escriure i llegir.
- Pots **centrar-te en el contingut**, no en el disseny.
- Es pot convertir fàcilment a HTML, PDF o altres formats.
- És ideal per a **documentació tècnica**, apunts o webs senzilles.

---

## On puc escriure Markdown?

Pots escriure Markdown en qualsevol editor de text, però per veure’l amb format, et recomanem:

- [Dillinger.io](https://dillinger.io)
- [StackEdit](https://stackedit.io)
- Bloc de notes + extensió Markdown Viewer (si utilitzes navegador)
- Visual Studio Code amb extensió Markdown

## Sintaxi bàsica

### Títols

Utilitza `#` per a crear títols:

```markdown
# Títol principal
## Subtítol
### Títol de tercer nivell
```

### Text en negreta i cursiva

```markdown
*Text en cursiva*
**Text en negreta**
```

### Llistes

**Amb punts (no ordenada):**

```markdown
- Primer punt
- Segon punt
```

**Numerada:**

```markdown
1. Primera cosa
2. Segona cosa
```

### Enllaços

```markdown
[Nom visible](https://llocweb.com)
```

Exemple:  
[GitHub](https://github.com)

### Imatges

```markdown
![Descripció](https://exemple.com/imatge.jpg)
```

Exemple:  
![Exemple d’imatge](https://download.logo.wine/logo/Markdown/Markdown-Logo.wine.png)

### Taules

```markdown
| Ferramenta | Nivell  |
|------------|---------|
| Markdown   | Bàsic   |
| HTML       | Mitjà   |
```

### Cites (frases inspiradores)

```markdown
> Esta és una frase inspiradora.
```

### Codi

**Codi curt dins del text:**

```markdown
Aquest és un `fragment` de codi curt.
```

**Bloc de codi:**

Amb tres cometes invertides (```) al principi i al final:

<pre>
```html
<h1>Hola món!</h1>
```
</pre>
